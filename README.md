# NETFLIX DATA ANALYSIS

📌Project Overview

This project focuses on analyzing Netflix Movies and TV Shows data using Python and Power BI.
The dataset was cleaned, transformed, analyzed, and visualized to uncover meaningful insights about Netflix content trends, genres, ratings, countries, and release patterns.
***

🛠 Tools & Technologies Used

-Python 

-Pandas

-NumPy

-Matplotlib

-Seaborn

-Power BI 
***

📂 Dataset Information

The dataset contains information about:

Movies & TV Shows

Directors

Cast

Countries

Ratings

Genres

Release Year

Duration

Date Added on Netflix
***

🧹 Data Cleaning Performed

The following cleaning steps were performed:

Removed duplicate records

Handled missing values

Converted date columns into datetime format

Fixed incorrect data types

Extracted month and year from date_added

Created new useful features

🔍 Key Insights

Movies dominate Netflix content library.

TV-MA is the most common content rating.

United States has the highest Netflix content.

Drama is the most popular genre.

Netflix content significantly increased after 2015.

Most TV Shows contain 1–2 seasons.
